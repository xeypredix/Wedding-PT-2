# Wedding Invitation Website
**Run:** open `index.html` in a browser (no server needed; internet needed once for Google Fonts).

**Change names, date, time, venue, address:** edit `weddingDetails` at the top of `countdown.js`. Use `<br>` for a line break in the address.

**Change the countdown date:** edit `weddingDate` just below it, format `"YYYY-MM-DDTHH:MM:SS"`.

**Photos:** put your files in `images/` named `photo1.jpg` … `photo6.jpg` and `couple.jpg` (replace the same names; keep JPG). Photo 1 is the large featured one. Portrait 3:4 works best for `couple.jpg`.

**Colours:** edit the variables at the top of `style.css`.


Performance: gallery images are optimized WebP files, below-the-fold images use lazy loading, and mobile animation/shadow work is reduced.
